# avtokino

Собирает один видеоролик из фото и видео в каталоге события. Работает на Ubuntu 24 и Windows 10.

## Установка

Нужны Python 3.10+ и ffmpeg (вместе с ffprobe).

Ubuntu 24:

```bash
sudo apt install ffmpeg python3-venv
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

Windows 10: поставьте Python с python.org и ffmpeg (сборка «full» с gyan.dev), добавьте `ffmpeg\bin` в PATH
или передавайте путь через `--ffmpeg` и `--ffprobe`. Затем `pip install -r requirements.txt` (numpy нужен только для `avtokino.tools sync`).

## Запуск

```bash
python -m avtokino /data/20240615_Wedding
python -m avtokino /data/20240615_Wedding --music /data/music --music-volume 0.25 --title
python -m avtokino /data/20240615_Wedding --dry-run      # только план и лог
```

Ролик `20240615_Wedding.mp4` и лог `20240615_Wedding.log` появятся в самом каталоге события.
Если ролик уже есть, создаётся `20240615_Wedding_v2.mp4` и т. д. Ранее собранные ролики в монтаж не попадают.

Полный список параметров: `python -m avtokino --help`.

## Как это работает

1. **Сканирование.** Обходятся все подкаталоги. Видео короче `--min-clip` (5 с) пропускаются,
   заодно отсекаются «живые фото» iPhone.
2. **Даты.** Приоритет: метаданные (EXIF, QuickTime) → дата в имени файла → дата файла.
   Часовой пояс определяется сам: по файлам, где он записан явно (EXIF OffsetTime, iPhone),
   и по видео, у которых есть и UTC-метка, и местное время в имени. Если не вышло, берётся `--tz`
   или пояс компьютера. Файлы идут по времени. Если дата файла выходит за период из имени каталога
   (с запасом `--date-tolerance`, по умолчанию 6 ч; для `YYYYMM`/`YYYYMMXX` — весь месяц), файл ставится
   в конец ролика, такие файлы между собой тоже идут по времени.
   Если у устройства были сбиты часы, задайте поправку: что показывали часы и сколько было на самом деле,
   например `--time-fix "2016-01-04 23:02:42 -> 2025-06-20 09:48:00"`. Поправка пробуется только
   на файлах вне периода события; если с ней файл попадает в период, он получает исправленное время
   и встаёт на своё место. Поправок может быть несколько, они пробуются по порядку, первая подошедшая
   применяется.
3. **Базовые параметры.** Разрешение, кодек и частота кадров берутся у видео с наибольшим разрешением
   (приводится к 16:9; вертикальное 1080x1920 даёт кадр 1920x1080). Всё можно задать параметрами.
4. **Видео** копируется без перекодировки, если совпадает кодек, разрешение, частота кадров (±1%),
   нет поворота, HDR, чересстрочности и битрейт не выше `--vbitrate`. Иначе перекодируется
   с качеством CRF и потолком `--vbitrate`, с чёрными полями при другом соотношении сторон.
   HDR переводится в SDR.
5. **Фото** — кадр с плавным зумом 5% (приближение и отдаление по очереди), 5 с;
   в серии больше 5 фото подряд — по 3 с. Ориентация из EXIF учитывается.
6. **Звук** всегда пересобирается в одну дорожку AAC 48 кГц: живой звук клипов, тишина под фото.
   Музыка из `--music` идёт по алфавиту по кругу, с выравниванием громкости, перекрытием треков,
   приглушением под живым звуком (`--no-ducking` отключает) и затуханием в конце.
7. Сегменты склеиваются через MPEG-TS, поэтому клипы с разных камер стыкуются без перекодировки.

Дополнительно:

- `--gopro-trim [СЕК]` — отрезать конец у роликов GoPro (по именам `GOPR0123`, `GP010123`, `GH010123`,
  `GX010123`), без числа 3 с: убирает момент выключения камеры рукой. `--min-clip` для GoPro
  проверяется уже после обрезки.
- `--caption` — подпись в правом нижнем углу: название и дата, выровнены по правому краю, белый текст
  с чёрной обводкой. Показывается первые `--caption-duration` секунд (10), плавно появляется и исчезает.
  Текст по умолчанию берётся из имени каталога («Август 2014», «31 июля – 3 августа 2014»),
  заменить: `--caption-name "Корпоратив DNS. Теплое море."`, `--caption-date "Август 2014"`.
  Шрифт: `--caption-font Roboto-Regular.ttf`. Видео, на которые попадает подпись, перекодируются.
  Если включён титр, подпись появляется сразу после него.
- `--title-text СТРОКА` — свой текст титра; каждый `--title-text` даёт отдельную строку, первая крупнее.
  Включает титр сам. Длительность: `--title-duration 4`.
- `--photo-fit cover` — фото на весь кадр с обрезкой краёв; по умолчанию `contain` (целиком, с полями).
  Вертикальные фото даже в режиме `cover` вставляются целиком, с полями.

- `--shift "МАСКА=СЕК"` — сдвинуть определённую дату съёмки файлов по маске на СЕК секунд вперёд
  (или назад со знаком минус): `--shift "DSC*.jpg=-3600"`, `--shift "Olympus/*=10800"`. Маска без «/»
  сравнивается с именем файла, с «/» — с путём от каталога события; регистр не важен. Сдвиг применяется
  до проверки периода события и `--time-fix`. Можно указать несколько, к файлу применяется первый подошедший.
- `--music-shuffle` — брать треки фоновой музыки в случайном порядке (каждый запуск свой порядок,
  он записывается в лог).
- `--long-video СЕК` — в логе отдельным списком перечисляются видео длиннее заданного (по умолчанию 60 с):
  дата съёмки, длительность и имя файла. `0` отключает список.
- `--exclude КАТАЛОГ` — не обрабатывать каталог. Можно указать имя (исключается на любом уровне вложенности),
  путь от каталога события (`Mobile/Screenshots`) или маску (`*_old`); регистр не важен. Опцию можно
  повторять.

Прочие опции: `--transition fade` (переходы через чёрное, перекодирует все клипы), `--title` (титр с
названием и датой события), `--safe` (перекодировать всё), `--jobs N` (параллельный рендер).

## Команды для отдельных файлов

Отдельная утилита `python -m avtokino.tools <команда>`. Список команд: `python -m avtokino.tools -h`.

### trim: вырезать кусок видео

Режет без перекодировки (`-c copy`), сохраняет метаданные (дату съёмки, модель камеры, потоки GoPro)
и даты файла, включая дату создания в Windows. Результат кладётся рядом с исходником:
`<имя>_trim_<параметры>.<расширение>`.

```bash
python -m avtokino.tools trim GOPR4745.MP4 --start 10 --end 25        # GOPR4745_trim_10-25.MP4
python -m avtokino.tools trim GOPR4745.MP4 --start 10                 # GOPR4745_trim_10-end.MP4
python -m avtokino.tools trim 00082.MTS --cut-start 3                 # 00082_trim_start3.MTS
python -m avtokino.tools trim 00082.MTS --cut-end 2                   # 00082_trim_end2.MTS
python -m avtokino.tools trim 00082.MTS --cut-start 3 --cut-end 2     # 00082_trim_start3_end2.MTS
```

`--start/--end` и `--cut-start/--cut-end` вместе не используются. Существующий результат не
перезаписывается без `--force`.

Без перекодировки кусок может начаться только с ключевого кадра, поэтому начало обычно получается
на долю секунды (у AVCHD до 1 с) раньше заданного; утилита пишет, на сколько. У .MTS дата съёмки
в результате соответствует фактическому началу куска. Субтитры .MTS (наложение даты у Sony)
не переносятся: ffmpeg не умеет их записывать.

Если и исходник, и вырезанный кусок лежат в каталоге события, в фильм попадут оба. Исходник
лучше убрать в подкаталог и исключить его через `--exclude`.

### timelapse: ролик из последовательности фото

Одно фото = один кадр. Берутся все фото каталога в порядке имён (`IMG_9` раньше `IMG_10`).
Ролик `<каталог>.mp4` сохраняется в том же каталоге (если такой уже есть, то `<каталог>_v2.mp4` и т. д.).

```bash
python -m avtokino.tools timelapse E:\photo\20240601_Sunset                          # 15 кадр/с, размер фото, до 15 Мбит/с
python -m avtokino.tools timelapse E:\photo\20240601_Sunset --fps 25 --resolution 1920x1080 --max-bitrate 10
```

- `--fps` — частота кадров (15);
- `--resolution ШxВ` — размер кадра (по умолчанию как у первой фотографии); фото другого формата
  вписываются целиком с чёрными полями;
- `--max-bitrate МБИТ` — максимальный видеопоток в Мбит/с (15);
- `--crf` (20), `--preset` (medium), `--vcodec h264|hevc` — качество, скорость и кодек.

Битое фото пропускается, вместо него повторяется предыдущий кадр. Дата съёмки первого фото
записывается в метаданные ролика, так что avtokino поставит его на правильное место в хронологии.

### rotate180: перевернуть видео

Без перекодировки: в контейнере меняется только пометка поворота, её учитывают плееры и сам avtokino.
Метаданные и даты файла сохраняются. Результат: `<имя>_rotate180.<расширение>` рядом с исходником.
Можно передать несколько файлов или масок; маски раскрывает сама утилита, так что в Windows они тоже работают.

```bash
python -m avtokino.tools rotate180 E:\video\GOPR4745.MP4
python -m avtokino.tools rotate180 "E:\video\GOPR*.MP4" "E:\video\0008?.MTS"
```

- Повторный поворот уже повёрнутого файла возвращает его в нормальное положение.
- В .MTS, .AVI и .MKV пометки поворота нет, поэтому такие файлы сохраняются в MP4 (поток не
  перекодируется, меняется только контейнер, субтитры .MTS не переносятся). Дата съёмки
  записывается в метаданные MP4.
- Файлы с `_rotate180` в имени по маске не берутся; существующий результат не перезаписывается без `--force`.

### sync: рассинхронизация двух камер по звуку

Для двух роликов, снятых одновременно разными камерами, находит точный сдвиг между ними по звуку
(точность лучше 0,01 с, то есть меньше кадра). Нужен numpy: `pip install numpy`.

```bash
python -m avtokino.tools sync E:\video\00082.MTS E:\video\GOPR4745.MP4
```

Пример ответа:

```
A начал запись на 3.470 с раньше B: один и тот же звук в A на 3.470 с дальше от начала.
Момент 0:00.000 в A соответствует −0:03.470 в B.
  в кадрах A (50.000 кадр/с): 173.5
  в кадрах B (29.970 кадр/с): 104.0
Уверенность: 25.3 (надёжно)
По метаданным B начат на +12.00 с относительно A, по звуку на +3.470 с.
Чтобы avtokino считал время B по часам A: --shift "GOPR4745.MP4=-8.53"
```

Сначала сдвиг ищется грубо по всплескам громкости во всём звуке (любой величины, даже если
ролики перекрываются лишь частично), затем уточняется на общем участке до 60 с.
Уверенность ниже 1,5 значит, что общего звука не нашлось (код выхода 3).
`--max-offset СЕК` ограничивает поиск, `--max-duration СЕК` читает только начало очень длинных файлов.
