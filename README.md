# avtokino

Собирает один видеоролик из фото и видео в каталоге события. Работает на Ubuntu 24 и Windows 10.

## Установка

Нужны Python 3.10+ и ffmpeg (вместе с ffprobe).

Ubuntu 24:

```bash
sudo apt install ffmpeg python3-venv
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
```

Windows 10: поставьте Python с python.org и ffmpeg (сборка «full» с gyan.dev), добавьте `ffmpeg\bin` в PATH
или передавайте путь через `--ffmpeg` и `--ffprobe`. Затем `pip install -r requirements.txt`.

## Запуск

```bash
python -m avtokino /data/20240615_Wedding
python -m avtokino /data/20240615_Wedding --music /data/music --music-volume 0.25 --title
python -m avtokino /data/20240615_Wedding --dry-run      # только план и лог
```

Ролик `20240615_Wedding.mp4` и лог `20240615_Wedding.log` появятся в самом каталоге события.
Если ролик уже есть, создаётся `20240615_Wedding_v2.mp4` и т. д. Ранее собранные ролики в монтаж не попадают.

Полный список параметров: `python -m avtokino --help`.

## Как это работает

1. **Сканирование.** Обходятся все подкаталоги. Видео короче `--min-clip` (5 с) пропускаются,
   заодно отсекаются «живые фото» iPhone.
2. **Даты.** Приоритет: метаданные (EXIF, QuickTime) → дата в имени файла → дата файла.
   Часовой пояс определяется сам: по файлам, где он записан явно (EXIF OffsetTime, iPhone),
   и по видео, у которых есть и UTC-метка, и местное время в имени. Если не вышло, берётся `--tz`
   или пояс компьютера. Файлы идут строго по времени, фильтра по дате каталога нет.
3. **Базовые параметры.** Разрешение, кодек и частота кадров берутся у видео с наибольшим разрешением
   (приводится к 16:9; вертикальное 1080x1920 даёт кадр 1920x1080). Всё можно задать параметрами.
4. **Видео** копируется без перекодировки, если совпадает кодек, разрешение, частота кадров (±1%),
   нет поворота, HDR, чересстрочности и битрейт не выше `--vbitrate`. Иначе перекодируется
   с качеством CRF и потолком `--vbitrate`, с чёрными полями при другом соотношении сторон.
   HDR переводится в SDR.
5. **Фото** — кадр с плавным зумом 5% (приближение и отдаление по очереди), 5 с;
   в серии больше 5 фото подряд — по 3 с. Ориентация из EXIF учитывается.
6. **Звук** всегда пересобирается в одну дорожку AAC 48 кГц: живой звук клипов, тишина под фото.
   Музыка из `--music` идёт по алфавиту по кругу, с выравниванием громкости, перекрытием треков,
   приглушением под живым звуком (`--no-ducking` отключает) и затуханием в конце.
7. Сегменты склеиваются через MPEG-TS, поэтому клипы с разных камер стыкуются без перекодировки.

Дополнительно:

- `--gopro-trim [СЕК]` — отрезать конец у роликов GoPro (по именам `GOPR0123`, `GP010123`, `GH010123`,
  `GX010123`), без числа 3 с: убирает момент выключения камеры рукой. `--min-clip` для GoPro
  проверяется уже после обрезки.
- `--caption` — подпись в правом нижнем углу: название и дата, выровнены по правому краю, белый текст
  с чёрной обводкой. Показывается первые `--caption-duration` секунд (10), плавно появляется и исчезает.
  Текст по умолчанию берётся из имени каталога («Август 2014», «31 июля – 3 августа 2014»),
  заменить: `--caption-name "Корпоратив DNS. Теплое море."`, `--caption-date "Август 2014"`.
  Шрифт: `--caption-font Roboto-Regular.ttf`. Видео, на которые попадает подпись, перекодируются.
- `--photo-fit cover` — фото на весь кадр с обрезкой краёв; по умолчанию `contain` (целиком, с полями).
  Вертикальные фото в режиме `cover` теряют большую часть кадра.

Прочие опции: `--transition fade` (переходы через чёрное, перекодирует все клипы), `--title` (титр с
названием и датой события), `--safe` (перекодировать всё), `--jobs N` (параллельный рендер).
